# ICT بالعربي — 6.9.19.9 | شاشة إقلاع واحدة بشعار شفاف

## الهدف
- إزالة شاشة الشعار الإضافية التي ظهرت بعد شاشة Android.
- نقل صورة الشعار الشفاف إلى أيقونات Manifest المستخدمة في إقلاع PWA على Android/Chrome.
- الإبقاء على التصميم الأصلي للشعار، من دون إعادة رسم أو تغيير ألوانه.

## التثبيت
ارفع ملفات الحزمة إلى جذر GitHub واستبدل index.html وmanifest.json وsw.js؛ أضف صورتي PNG الجديدتين. **لا تحذف icon-192.png أو icon-512.png**؛ تبقيان محفوظتين بالمستودع، لكن الـManifest الجديد يشير إلى الصور الشفافة.

## هام — قيد Android
ليس في تطبيق PWA ضمان لفصل أيقونة الشاشة الرئيسية عن شعار شاشة الإقلاع. عندما تستخدم صور Manifest الشفافة، قد تتغير صورة أيقونة التطبيق المثبتة (الخلفية فقط أو طريقة عرضها بحسب الجهاز). لا يمكن ضمان إبقاء الأيقونة البيضاء القديمة وعرض صورة مختلفة شفافة في شاشة Android النظامية على كل الأجهزة.

**للتأكد من تحديث شاشة Android النظامية:** أغلق التطبيق وأعد فتحه بعد النشر. إذا بقي الشعار القديم، قد يلزم إزالة اختصار/تثبيت تطبيق PWA القديم ثم تثبيته مجددًا؛ احفظ بياناتك المحلية وصدّر نسخة احتياطية من مساحتي أولًا لأن إزالة التطبيق قد تزيل التخزين المحلي عند بعض الأجهزة.

لا يمكننا التحكم في رسوم انتقال النظام وقد يفرض Android خلفية أو قناعًا بحسب إصدار النظام ومشغل الشاشة الرئيسية. لا نضيف طبقة شعار داخل الموقع.

التحديث لا يغيّر وظائف التداول أو الهيدر أو شريط التنقل أو ملفات أيقونات الموقع الأصلية.
