# ICT بالعربي 7.0 — المرحلة 4C.2: اختبار نموذج Sweep → MSS → FVG المركب

## طريقة التركيب
ارفع **فقط** ملفات هذه الحزمة إلى جذر مستودع موقع GitHub Pages فوق تحديث 4C السابق، مع استبدال `research.html` و`sw.js`، وإضافة ملفات المحرك والواجهة الثلاثة. لا تحذف بقية ملفات المشروع.

## أين تظهر الإضافة؟
المزيد ← مختبر الأبحاث ← «اختبار النموذج المركب — Sweep → MSS → FVG».
الرابط: `research.html#ict-composite-4c2`.

## الجديد المرئي
اختيار السوق والأصل والإطار (5/15/60 دقيقة) وتكلفة مفترضة R؛ طلب بيانات حقيقية من موصل Bybit USDT أو موصل الأسواق التقليدية المعتمد؛ تقرير زمن تطوير أول 70% واختبار لاحق 30%؛ عرض الحالات غير المحسومة، والنتائج التاريخية الأخيرة بتوقيتي نيويورك وفلسطين؛ تصدير JSON.

## تعريف النموذج المبرمج (نسخة بحثية ثابتة)
- القمم/القيعان تأكيد نافذة Pivot=2 عبر محرك 2D، دون تأكيد لحظي قبل إغلاق الشموع اللازمة.
- سحب سيولة ثم MSS في الاتجاه المقابل للسحب خلال 12 شمعة، ثم FVG في نفس اتجاه MSS خلال 5 شموع من MSS.
- نموذج يُعرف عند اكتمال آخر حدث. منطقة دخول منتصف FVG، ووقف وراء طرف السحب، وهدف افتراضي 2R. الدخول افتراضي خلال 6 شموع بعد التكوّن.
- تقييم بعد الدخول حتى 20 شمعة. عندما تلمس شمعة الدخول مستوى خروج أيضًا، أو تلمس شمعة لاحقة الوقف والهدف معًا، النتيجة «غير حاسمة» لأن OHLC لا يبين ترتيب الحركة.
- تُستبعد حالات تدريب قد تمتد معلومات نتيجتها إلى بداية الاختبار اللاحق. التكاليف بوحدة R تقديرية.
- الاختبار يعمل فقط على **آخر مقطع شموع مكتملة متصل** ويعتمد على آخر 100 حدث/منطقة يحتفظ بها 2D، وقد لا يغطي كافة التاريخ المستورد.

## ما لم ينفذ بعد
لا توجد نسب صلاحية معتمدة للنموذج؛ كل الاختبارات استكشافية وتتطلب عينات أكبر وبيانات tick/تكاليف حقيقية واختبارات Walk-Forward وتجربة أمامية. بقية نماذج 4A (Silver Bullet و2022 Model وOTE وغيرها) ما زالت **غير مختبرة آليًا كنماذج كاملة**. لا إشارات تداول أو تنفيذ أو إشعارات مستمرة.

## الاختبارات
- اختبارات Node: ثماني حالات تتضمن الربح والخسارة والإبطال وعدم التفعيل والغموض وعدم كفاية العينة.
- `node --check` للمحرك والواجهة؛ مراجعة المراجع داخل research.html وsw.js؛ فحص سلامة ZIP.
- تعذر اختبار الواجهة Chromium المحلي بسبب سياسة البيئة `ERR_BLOCKED_BY_ADMINISTRATOR`. لا يعد هذا اختبارًا ناجحًا للموقع المنشور.
