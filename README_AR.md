# ICT بالعربي 7.0 — المرحلة 7A: حسابات متعددة وربط سجل الصفقات

## التركيب
ارفع محتويات هذا ZIP فقط إلى جذر مستودع GitHub Pages فوق آخر إصدار معتمد للمرحلة 6C. استبدل ملفات `workspace.html` و`smart-desk.html` و`smart-desk.js` و`sw.js`، وأضف الملفات الأربعة التي تبدأ بـ`ict-accounts-707a`.

## ما ستراه
1. `workspace.html#dashboard`: أعلى تبويبات «مساحتي» تظهر لوحة «حساباتي — الشخصي والممول». أضف حسابًا شخصيًا أو ممولًا، واضبط الحد الخاص بالصفقة وحالته الحالية. حدد الحساب النشط واختبر مبلغ مخاطرة مقترح.
2. `smart-desk.html#dna`: داخل نموذج إضافة الصفقة يظهر حقل الحساب، وفي شريط تصفية نتائج Trader DNA يظهر مرشح حسب الحساب. تظهر الحسابات المدخلة على الجهاز نفسه فقط.
3. الصفقات القديمة تظهر «غير منسوبة»، ولا تُنسب تلقائيًا لحساب جديد. احتفظ بنسخة احتياطية من بيانات الجهاز قبل تحديثات كبيرة.

## حدود التطبيق
- لا تُعدّل الحزمة سجلات `localStorage` القديمة عند التركيب، ولا تستبدل قاعدة سجلات الصفقات ولا تحذفها. حفظ صفقة جديدة بعد التحديث يحتفظ بمعرّف الحساب المختار. استيراد نسخ Trader DNA القديمة يستمر بالعمل.
- حارس الحساب الممول القديم ما زال مستقلًا كي لا يتغير حسابه أو بياناته السابقة. فحص حدود الحسابات الممولة في 7A تقديري ويدوي، وليس تطبيقًا آليًا خاصًا بأي شركة تمويل. `Equity` ومرجع اليوم وأعلى رصيد تُحدث يدويًا؛ لا توجد صلة بالوسيط أو مراقبة آنية.
- حسابات التداول الشخصية تطبق فقط الحد الذي يحدده صاحب الحساب لكل صفقة، دون افتراض حدود شركات التمويل.
- لا توجد مزامنة حسابات بين الأجهزة أو حماية بكلمة مرور؛ بيانات الحسابات المحلية حساسة؛ استخدم زر «تصدير حساباتي JSON» داخل 7A لإنشاء نسخة خاصة بهذه الحسابات، ويمكن استيرادها دون استبدال الحسابات الموجودة. خزنة البيانات القديمة لا تضم حسابات 7A تلقائيًا.
- أرباح Trader DNA بوحدة R لا تتحول تلقائيًا إلى رصيد الحساب أو Equity، لتجنب افتراضات تحويل خاطئة.

## التحقق
- فحص JavaScript لجميع الملفات المعدّلة.
- اختبار حسابات شخصية وممولة وإنشاء/حفظ/اختيار وحساب سقف المخاطرة عبر محاكاة التخزين.
- فحص بُنية HTML وربط الأصول ونموذج تسجيل الصفقة والحقل الجديد.
- فحص ZIP.
- لم يُجرَ اختبار تفاعلي كامل على GitHub Pages المنشور. متصفح الاختبار محظور من فتح `127.0.0.1` في البيئة الحالية.
