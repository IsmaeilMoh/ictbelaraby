# ICT بالعربي — تعديل شعار شاشة البداية (حزمة صغيرة فوق 6.9.19.8)

## ما الذي تغيّر؟
- إضافة `startup-logo-transparent.png`: الصورة الأصلية نفسها مع إزالة الخلفية البيضاء فقط بواسطة شفافية PNG؛ دون تغيير عناصر الشعار أو لونها.
- تحديث `index.html` لإظهار الشعار الشفاف على طبقة بداية داخل تطبيق PWA عند فتحه، ثم إخفائها تلقائيًا.
- لم تُمس `icon-192.png` أو `icon-512.png` أو `manifest.json` أو تصميم الصفحة والهيدر أو التنقل.

## تنبيه فني ضروري
شاشة الإقلاع الأولى **الخاصة بنظام Android/Chrome** تستمد الصورة من أيقونة Manifest. لا يوفر PWA صورة Splash منفصلة مضمونة عن أيقونة الشاشة الرئيسية في كل الأجهزة. لذا هذه الحزمة تضبط **طبقة بدء الموقع بعد الشاشة النظامية**، لكنها لا تستطيع أن تضمن إزالة المربع الأبيض من شاشة Android الأصلية دون تغيير الأيقونات المرتبطة بالتطبيق.

## التركيب
ارفع `index.html` و`startup-logo-transparent.png` إلى جذر المستودع، مع استبدال `index.html` فقط. لا تحذف أو تستبدل أيقونتي التطبيق.
إذا لم يظهر التغيير، أغلق التطبيق وافتحه مجددًا، ثم حدّث الموقع لتجاوز ذاكرة PWA القديمة.
