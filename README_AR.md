# ICT بالعربي 7.0 — توحيد تصميم مركز جميع الأدوات

تحديث جزئي **خاص بصفحة الأدوات فقط** على أساس التحديث السابق الذي وضع الأدوات في «المزيد».

## الملفات التي ترفعها إلى جذر GitHub
- `tools.html` — نفس هيدر الموقع الموحد، زر المظهر، التذييل وتحذير المخاطر؛ تنسيق الأدوات في 8 مجموعات.
- `ict-tools-unified-7012.css` — بطاقات زجاجية متجاوبة، خطوط وأيقونات SVG خطية موحدة مع روح الموقع، ودعم المظهرين.
- `sw.js` — تغيير إصدار الكاش وإضافة الملف الجديد.

## ما لم يتغير
لا تعديل لملفات المحركات أو روابط الأدوات الثلاثين، ولا تعديل لشريط التنقل السفلي أو مدخل «المزيد». بعد رفع تحديث «الأدوات في المزيد فقط»، يظل مركز الأدوات في «المزيد» فقط.

## اختبار يدوي
1. افتح الموقع ← المزيد ← مركز جميع الأدوات.
2. قارن الهيدر (الشعار وزر المظهر) وتذييل المخاطر مع غرفة المتداول.
3. بدّل بين الوضعين الفاتح والداكن.
4. افتح من الموبايل وتحقق من عدم وجود شريط ثان أو تمرير أفقي.
5. افتح أداة من كل مرحلة واختبر أن روابطها تؤدي إلى الموضع المطلوب.
6. إن بقي التنسيق القديم بسبب PWA: أغلق التطبيق وافتحه بعد نشر تحديث `sw.js`؛ يمكن إجراء تحديث قسري من المتصفح.

هذا تحديث تصميم وتنقل فقط وليس تغييرًا في توليد التوصيات.
