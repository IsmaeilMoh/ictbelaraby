ماذا سيتغير بعد التركيب؟
- أعلى مراقب الشموع في صفحة موثوقية البيانات سيظهر "اكتشاف عقود الفوركس والمعادن والأسهم عبر Bybit".
- اختيار Forex أو Commodity/Metals أو Stocks أو ETF، والضغط لجلب قائمة العقود المتاحة فعليًا عبر Bybit V5.
- البحث بالرمز أو اسم الأصل المرجعي، ثم استخدام العقد المحدد في نفس لوحة متابعة الشموع السابقة.
- التخزين والفجوات والمزامنة من 2B تستمر للعقود الجديدة بشرط عمل IndexedDB في المتصفح.
- عند عدم توفر فئة أو رمز، يعرض الموقع عدم التوفر ولا يصنع بيانات افتراضية.

مهم عن طبيعة البيانات:
- الربط هنا بعقود Bybit TradFi Perpetuals عبر V5 category=linear، وليس بأسعار Bybit CFD/MT5.
- عقد XAUUSDT ليس بالضرورة سعر XAUUSD، وEURUSDUSDT ليس بالضرورة سعر زوج EURUSD عند وسيط MT5.
- فئة ETF هي صناديق تتبع مؤشرات، وليست بالضرورة السعر المباشر للمؤشر NAS100/US500.
- فئات TradFi التي لا تتيح عقودًا عامة عبر V5 لن تظهر في هذه المرحلة. ربط CFD/MT5/مؤشرات نقدية أو مزود إضافي يتطلب واجهة مستقلة وتصاريح/اشتراكًا عند الاقتضاء.
- تعرض الأسعار وفق مدى حداثة البيانات المتاحة، لكن إشارات التداول وتحليل ICT غير منفذين بعد.
- لا يوجد اتصال أو تخزين أثناء إغلاق التطبيق، ولا تُطلب مفاتيح API خاصة.

اختبار سريع:
1) ارفع ملفات الحزمة إلى جذر المستودع مع الاستبدال.
2) افتح trust.html#ict-tradfi-2c أثناء الاتصال بالإنترنت.
3) اختر المعادن واضغط "جلب العقود من Bybit".
4) ابحث عن XAU، واختر عقدًا يظهر فعلًا، ثم اضغط "استخدام العقد في مراقب الشموع".
5) اضغط "اتصال وجلب الشموع" في اللوحة أسفلها. إذا لم يظهر عقد XAU تحقق من إتاحة API وبلد الاتصال ورمز العقد الحقيقي.
6) كرر الاختبار للفوركس والأسهم وETF. جرّب إعادة فتح الصفحة للتحقق من التخزين المحلي للشموع المكتملة.

فحوص منجزة: اختبارات موضعية عبر Node.js لتصنيف العقود، منع الرموز غير المؤكدة، صحة بيانات OHLC، وتحليل ردود API، ونجاح صياغة JavaScript، وسلامة ZIP.
القيود: لم يتم اختبار الاتصال الحي من موقع GitHub Pages المنشور أو قياس التوافق البصري في المتصفح على جهاز المستخدم. النتائج تعتمد على توفر API لدى Bybit في منطقة المستخدم.
