# ICT بالعربي — خارطة 7.0، المرحلة الأولى: محرك البيانات الموحد

**نقطة البناء:** النسخة الحالية المبنية فوق سلسلة 6.9.19.16. هذا تحديث جزئي، وليس إعادة تصميم للموقع.

## التثبيت
ارفع جميع الملفات الموجودة في ZIP إلى **جذر المستودع** كما هي. استبدل `trust.html` و`intelligence.html` و`research.html` و`smart-desk.html` و`workspace.html` و`sw.js`، وأضف الثلاثة:
- `ict-data-core-700.js`: المحرك المشترك القابل لإعادة الاستخدام.
- `ict-data-console-700.js`: لوحة فحص مصادر البيانات.
- `ict-data-console-700.css`: تنسيق اللوحة داخل مركز موثوقية البيانات.

لا تغيّر ملفات JSON المنشورة ولا تحذف أي ملفات قديمة. ولا حاجة إلى تغيير GitHub Actions أو إضافة مفاتيح API.

## طريقة الاستخدام
افتح **موثوقية البيانات** (`trust.html`) ثم انزل إلى **مركز تدقيق البيانات الموحدة** واضغط **فحص المصادر الآن**. يظهر تقرير للمصادر السبعة مع الحالة ووقت آخر تحديث وعدد السجلات وملاحظات الجودة. يمكنك تنزيل تقرير JSON. لا يرسل الفحص بيانات محلية أو مفاتيح أو معلومات من مساحتي.

## ما تم تنفيذه فعليًا
1. سجل مركزي لملفات السوق والأجندة والأخبار والتوصيات والتحليلات المنشورة؛ لا يجلب خدمات API خارجية.
2. توحيد رموز الأصول الشائعة، والعملات، والتوقيت UTC (مع بقاء عرض توقيت المستخدم من المتصفح).
3. تطبيع سجلات الأسعار والشموع والأحداث والأخبار والمنشورات، والتحقق من الأسعار والأوقات والقيم الناقصة.
4. فحص حداثة كل تسعيرة بشكل منفصل عن وقت تحديث ملف المصدر، وكشف النواقص والتكرار والأخطاء الجزئية.
5. محرك شموع OHLC قابل لإعادة الاستخدام: يرفض الارتفاع/الانخفاض المتناقض، والتوقيت غير المرتب، والقيم الناقصة.
6. واجهة تشخيص في صفحة موثوقية البيانات، وفحص يدوي عند الطلب، وتقرير قابل للتصدير.
7. إتاحة المحرك كـ `window.ICTDataCore` في مختبر السوق والأبحاث وغرفة المتداول ومساحتي للربط التدريجي بالمراحل القادمة، دون تجاوز محركاتها الحالية.

## حدود هذه المرحلة
- ليست مصدرًا جديدًا لأسعار OHLC أو البيانات اللحظية؛ لا تدّعي مراقبة تيك-بتيك أو بناء إشارات ICT تلقائيًا.
- لا تنقل الأخبار أو التقويم أو الأسعار إلى قاعدة بيانات خارجية. يستند كل تقييم إلى ما هو منشور وقت الفحص.
- لا تستبدل تلقائيًا محركات التداول القديمة؛ المرحلة الأولى تأسيس وتدقيق، والمراحل التالية تربط محرك ICT بهذا التوحيد.
- حدود الحداثة افتراضات فحص قابلة للتغيير: الأسعار 45 دقيقة، الأخبار 4 ساعات، الأجندة 7 أيام. هذه **ليست** ضمانات جودة سعر ولا صلاحية للتداول.
- لا تعتبر تحديث توصية بنهاية هدف أو وقف إثباتًا لتنفيذ المتداول.
- العملات الرقمية الدائمة ذات صيغة USDT تُطبع في هذه النسخة إلى رمز سوق مرجعي USD للبحث فقط؛ لا يعني ذلك تكافؤ عقود أو أسعار الوسطاء.

## فحوص القبول بعد الرفع
1. افتح `trust.html`، وتأكد أن اللوحة تظهر تحت العنوان وأن الفحص يعمل ويفتح تفاصيل مصدر.
2. تأكد أن أي مصدر غير متاح يظهر «غير متاح» ولا يمنع بقية المصادر من الظهور.
3. راجع ملف `market-movers.json`: يجب أن تُظهر لقطة قديمة حالة تأخر، لا سعرًا لحظيًا.
4. تأكد من أن روابط الرئيسية و«المزيد» والهيدر والثيم والتذييل لم تتغير.
5. جرّب تحديث الصفحة وإعادة فتح تطبيق PWA أثناء الاتصال لاستلام الـService Worker الجديد.

## الاختبارات التي أُجريت
اجتاز `node --check` للملفات البرمجية، واختبارات Node لعينات من ملفات JSON الحقيقية المحفوظة من المشروع (7 مصادر) وحالات التواريخ والأسعار والرموز والشموع والتكرارات. لا يوجد قياس تكامل عبر متصفح الموقع المنشور؛ يجب التحقق بعد التركيب.
