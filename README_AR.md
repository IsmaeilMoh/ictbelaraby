# ICT بالعربي 7.0 — المرحلة 4B: أرشيف الحالات التاريخية

## التركيب
ارفع ملفات ZIP إلى جذر مستودع GitHub Pages فوق الإصدار 4A. استبدل `research.html` و`sw.js`، وأضف الملفات الثلاثة الجديدة:
- `ict-case-engine-704b.js`: اكتشاف FVG تاريخية وتصنيف استجابة السعر وفق قاعدة اختبار واضحة، من دون افتراض نجاح النموذج الكامل.
- `ict-case-library-704b.js`: جلب الشموع الحقيقية من موصل Bybit أو موصل الأسواق التقليدية القائم، وعرض الحالات وإدارة المراجعات وتصديرها.
- `ict-case-library-704b.css`: واجهة متجاوبة في «مختبر الأبحاث».

الملفان `ict-live-feed-702a.js` و`ict-public-markets-702c2.js` موجودان أصلًا من المرحلتين 2A و2C، ولا تضمهما الحزمة لأنهما غير معدلين.

## ما الذي ستراه؟
افتح https://ismaeilmoh.github.io/ictbelaraby/research.html#ict-cases-4b
أو «المزيد» ← «مختبر الأبحاث» ثم قسم «دراسات حالات تاريخية — النجاح والفشل».

1. اختر سوقًا وأصلًا وإطارًا من 5 أو 15 أو 60 دقيقة، واضغط «جلب الشموع وبناء الحالات».
2. تظهر حالات FVG تاريخية عند توفر شموع مكتملة ومتتابعة وحركة سعر تستوفي شروط الفجوة.
3. التصنيفات: وصل إلى هدف 1R، وصل إلى الإبطال، لم يتفعّل، غير حاسم.
4. اختر حالة لرؤية التوقيت بنيويورك وفلسطين، والمنطقة ومستويات الاختبار وسبب التصنيف.
5. إذا راجعت الشارت، تستطيع ربط الحالة بنموذج من الستة، وتوثيق النتيجة يدويًا والأدلة والرابط؛ تحفظ المراجعة محليًا في المتصفح. يمكن تصدير JSON شامل.

## تعريف اختبار FVG التوضيحي
- لا يشمل نتائج نموذج ICT كاملًا؛ هو مكوّن بحثي فقط.
- FVG صعودية عندما `high[i-2] < low[i]`، وهبوطية عندما `low[i-2] > high[i]`، مع اتصال ثلاث شموع مكتملة. يستبعد الفجوات الضئيلة (أقل من 0.015% من سعر الإغلاق).
- دخول افتراضي عند منتصف الفجوة، حد الإبطال عند طرف الفجوة المقابل، وهدف 1R؛ نافذة متابعة لا تتجاوز 20 شمعة.
- في شمعة الدخول، إذا وصل السعر إلى الهدف أو الإبطال، نسجل «غير حاسم» لأن ترتيب الحركة مجهول.
- إن لُمس الهدف والإبطال خلال شمعة واحدة بعد التفعيل، نسجل «غير حاسم» أيضًا.
- إذا انتهى التاريخ المتاح قبل 20 شمعة من دون تفعيل، لا نعتبرها «لم يتفعّل» مؤكدة بل «غير حاسمة».
- أي انقطاع في تسلسل الشموع يمنع الجزم بالحكم بعده.
- لا يتضمن السبريد أو العمولة أو الانزلاق أو ظروف الأخبار؛ لا يجوز استنتاج نسب ربح حقيقية منه.
- كل الأوقات الحسابية UTC؛ العرض بتوقيت America/New_York وAsia/Gaza. لا يُعاد تجميع شموع 4H أو D من المصدر في هذا الجزء.

## اختبارات
- فحص Node.js للصياغة في ملفات JS الجديدة.
- اختبار مستقل لاستخراج حالة FVG وتصنيف ملامسة مستوياتها.
- اختبار Chromium معزول على 390 و1366 بكسل عبر موصل شموع اختباري، من دون أخطاء JS أو تمرير أفقي.
- فحص عناصر البحث والعرض وروابط الملفات وبنية الهيدر والتذييل وعدم تغيير أي مكون آخر.
- سلامة ملف ZIP وفحص أسمائه.

## حدود يجب معرفتها
- لم تجرَ تجربة مباشرة على GitHub Pages أو اتصال حي حقيقي بالمزود داخل بيئة الاختبار.
- البيانات المعروضة وقت التشغيل مأخوذة من Bybit أو Biquote وفق اختيارك؛ قد يفشل الاتصال إذا منعته الشبكة أو توقف المزود.
- حجم التاريخ لدى مزود الأسواق التقليدية محدود، ولذلك لا يغطي كامل السنوات وقد يقل عدد الحالات.
- الحالات ليست صفقات حقيقية ولا توصيات، ولا شهادة على نجاح Silver Bullet أو 2022 Model أو بقية تعريفات مكتبة 4A.
- حفظ المراجعات محلي ويتطلب الاحتفاظ ببيانات المتصفح؛ صدّر JSON احتياطيًا دوريًا.
- المرحلة 4C: نثبت قواعد كل نموذج، نجمع عيّنات تاريخية أوسع، نقيس النتائج خارج العينة ونفصل شروط التنفيذ والتكاليف.
