# ICT بالعربي 6.9.19.6 — توحيد وجهة زر «المزيد»

## الفكرة
الضغط على «المزيد» من أي صفحة يفتح الآن **قسم استكشف المنصة** الأصلي في الصفحة الرئيسية `./#more`، بنفس شكل الصفحة الرئيسية ومحتواها. لم نعد نفتح قائمة مختلفة أو نافذة منبثقة في الصفحات الداخلية.

## نطاق التحديث
- ملف `site-unity.js`: استبدال قائمة «المزيد» المنبثقة برابط مباشر، وتوحيد وجهة «المزيد» في روابط سطح المكتب أيضًا.
- ثماني صفحات داخلية: تحديث رقم تحميل ملف JavaScript لتجاوز كاش النسخ القديمة.
- لوحة النشر `admin.html`: إضافة رابط مباشر إلى «المزيد — كل الأقسام»، دون المساس بوظائف النشر.
- **لم يتم تعديل** `index.html` أو الهيدر أو CSS أو بيانات المستخدم.

## التركيب
ارفع الملفات إلى جذر مستودع GitHub واستبدل الملفات المطابقة، فوق 6.9.19 مع الإصلاحات الأخيرة للهيدر والتنقل. لا تحذف أي ملف آخر.

## التحقق بعد التركيب
1. من الصفحة الرئيسية اضغط «المزيد» فتظهر صفحة «استكشف المنصة».
2. من مختبر الأبحاث وغرفة المتداول ومساحتي اضغط «المزيد» في شريط الموبايل؛ يجب أن تظهر **نفس صفحة استكشف المنصة**.
3. من القائمة العلوية على اللابتوب افتح «المزيد»؛ الوجهة نفسها.
4. جرّب الرجوع للصفحة السابقة في المتصفح.
5. إذا ظهر السلوك القديم، أعد التحميل مع تجاوز كاش المتصفح أو افتح PWA من جديد.

### ملاحظة
فحوص الكود والروابط لا تعادل اختبارًا فعليًا للموقع المنشور على جميع الأجهزة.
