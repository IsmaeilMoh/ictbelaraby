# ICT بالعربي — إصلاح ثبات حجم الشريط العلوي 6.9.19.7

حزمة تحديث صغيرة توضع **فوق 6.9.19.6** مع إصلاحات الهيدر السابقة.

## ما تم إصلاحه
- تقليل تضخّم الهيدر في «مساحتي» وباقي الصفحات الداخلية، بما فيها لوحة الإدارة.
- تقييد ارتفاع الشريط والحشوات والحواف وصورة الشعار والنص وزر الثيم داخل المكوّن نفسه.
- إبطال تأثير الخلفية والحشوات القديمة على الحاوية الخارجية للهيدر.
- الإبقاء على الشكل الزجاجي والخطوط وألوان الثيم وروابط «المزيد» دون تعديل.
- تحميل CSS الجديد **بعد** ملفات الهيدر القديمة برقم إصدار مختلف لتجاوز الكاش.

## محتويات الحزمة
تسع صفحات HTML داخلية وملف CSS واحد. **لا يوجد index.html**؛ الصفحة الرئيسية هي المرجع ولم تتغير.

## التركيب
ارفع ملفات الحزمة إلى جذر مستودع GitHub، واستبدل صفحات HTML الموجودة، وأضف ملف CSS الجديد فقط.

## التحقق
تم التأكد من وجود ربط CSS الجديد في الصفحات التسع، وأن الحزمة لا تحتوي تغييرات JS أو ملفات المستخدمين. لم يكتمل تشغيل متصفح على صفحات الموقع الحقيقية في البيئة الحالية؛ افحص الارتفاع على هاتفك وعلى شاشة لابتوب، وخصوصًا «مساحتي» ثم «مختبر الأبحاث» و«لوحة النشر».
