# ICT بالعربي 7.0 — المرحلة 6C: مختبر المقارنة الاقتصادية

## طريقة التركيب
ارفع ملفات هذه الحزمة إلى جذر مستودع GitHub Pages **فوق المرحلة 6B المعتمدة**، واستبدل `index.html` و`sw.js` فقط، وأضف ملفات JS/CSS الثلاثة الجديدة. لا تحذف الملفات القديمة.

## ماذا ستلاحظ؟
افتح الصفحة الرئيسية -> «الأجندة» (`/#agenda`). أسفل لوحة قياس رد فعل الخبر 6B ستظهر «مختبر المقارنات الاقتصادية المتقدم».

1. اضغط «قراءة أحداث الأجندة»؛ يقرأ المحرك ملفات الأجندة الثلاثة نفسها من المرحلة 6A.
2. اختر السوق والأصل، وعملة الخبر، واكتب نوع الحدث إن رغبت (مثل CPI أو NFP)، وحدد شدة التأثير.
3. اضغط «إنشاء المقارنة». تفحص الأداة آخر 12 حدثًا سابقًا مطابقًا بوقت UTC واضح، وتطلب شموع الدقيقة المكتملة من مصدر السوق.
4. النتائج: 5 و15 و60 دقيقة؛ متوسط الحركة المطلقة والتغير الموقع والتذبذب، مع عدد الصالح والمستبعد لكل نافذة. جدول أنواع الأخبار، وجدول المفاجأة الاقتصادية حيث يتوفر actual وforecast بوحدات متوافقة، وتفاصيل المصدر والتوقيت بنيويورك وفلسطين.
5. اضغط «تصدير JSON» لتنزيل التقرير.

## ما جرى تطويره داخليًا
- تعريف مستقل لتطبيع عنوان الخبر وتحليل الحقول الرقمية؛ عدم خلط النسبة المئوية بالأعداد أو القيم غير الرقمية.
- فصل عدد الأحداث الصالحة بحسب كل نافذة زمنية؛ حد وصفي 5 أحداث، لا يُعتبر دلالة إحصائية ولا اختبارًا للربحية.
- تكامل مباشر مع محركات 6A و6B، دون نسخ تغذية اقتصادية جديدة أو تغيير حسابات الأخبار السابقة.
- إظهار أسباب عدم توفر التغطية والإبقاء على مصدر الشمعة واضحًا.
- عدم وضع مفاتيح API أو بيانات حساب تداول.

## القيود
- مصدر الأسواق التقليدية الحالي قد لا يوفر شموع دقيقة للأخبار التاريخية القديمة؛ لا تُستنتج نتائج من بيانات غير موجودة.
- جميع المقارنات وصفية؛ لا تثبت علاقة سببية أو اتجاهًا متوقعًا ولا تصلح لإصدار إشارة تداول آلية.
- الحسابات تمت محليًا في المتصفح، ولا تعمل بعد إغلاق التطبيق.
- تحليل المفاجأة لا يوحّد الأهمية الاقتصادية لاختلاف أنواع الأحداث ولا يضبط العوامل الخارجية المصاحبة.
- لم تُختبر البيانات المباشرة على الموقع المنشور؛ يجب فحصها بعد رفع الملفات.

## الاختبارات المنفذة
- `node --check` للملفات البرمجية الجديدة وService Worker.
- `node test_6c.cjs` لاختبار التصفية وتجميع العينات والمفاجأة الاقتصادية ونقص البيانات.
- اختبار متصفح معزول على 390px و1366px باستجابات بيانات اختبارية، يشمل أزرار التحميل والمقارنة والتصدير وعدم التمرير الأفقي.
- سلامة ZIP ومسارات ملفات الواجهة.
