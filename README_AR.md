ICT بالعربي 7.0 — المرحلة 3A | السياق اليومي والأسبوعي
=====================================================

التركيب:
1) فوق آخر تحديث معتمد للمرحلة 2E (نيويورك وفلسطين)، ارفع محتويات هذه الحزمة إلى جذر مستودع GitHub Pages.
2) استبدل trust.html و sw.js، وأضف الملفات الثلاثة ict-context-*.js/css. لا تحذف ملفات أخرى.
3) بعد النشر افتح trust.html#ict-context-3a واضغط «حساب سياق السوق من الشموع».
4) إذا بقيت نسخة قديمة على الهاتف، أغلق PWA وافتحها مجددًا بعد وصول تحديث Service Worker.

الذي سيظهر:
- قمة وقاع آخر شمعة يومية مكتملة ووسط نطاقها.
- قمة وقاع الأسبوع السابق إذا كانت كل أيامه المتوقعة متوفرة في التاريخ المسترجع؛ وإلا يظهر تحذير.
- آخر إغلاق ساعة حديث وموقعه بالنسبة إلى نطاق اليوم السابق.
- أقرب قمة/قاع مرجعي أعلى وأسفل السعر من مستويات اليوم/الأسبوع.
- أوقات الفحص والمرجع بنيويورك وفلسطين، مع الاحتفاظ بUTC للحسابات الداخلية.
- مصدر الشموع والشموع المستبعدة والتنبيهات على البيانات المتأخرة.

الأسواق: Bybit لعقود الكريبتو الدائمة USDT؛ Biquote للفوركس والمعادن والمؤشرات والأسهم والطاقة حسب تغطية المصدر.

قيود واضحة:
- الإطار اليومي لدى المصدر هو UTC، ولا تُنسب مستوياته خطأً إلى يوم جلسة نيويورك. بناء مستويات جلسة نيويورك الفعلية يحتاج بيانات تاريخية داخل اليوم بتغطية كافية عبر تغيّر DST.
- العرض لا يعني توقع اتجاه السوق أو توصية دخول.
- التوقيت الصيفي/الشتوي لعرض الأوقات يُحسب تلقائيًا عبر America/New_York وAsia/Gaza.
- التنقل والهوية البصرية والتذييل ومركز 2D/2E لا تتغير.
- لا يتم جلب أي بيانات تلقائيًا عند فتح الصفحة، حفاظًا على الإنترنت.
- لم يُجرَ اتصال حي على موقع GitHub Pages ضمن بيئة الاختبار، ويلزم اختبار المستخدم بعد النشر.

الفحص المحلي: اجتازت 8 حالات اختبار منطقية (الأسبوع المكتمل/الناقص، السوق الكريبتو، الشمعة غير المكتملة، الشموع غير الصالحة، حداثة الساعة، حدود الأسبوع)، وفحص JavaScript وسلامة ZIP.

التالي بعد اعتماد هذه المرحلة: 3B السيناريوهات الصعودية والهبوطية المشروطة مع شروط التأكيد والإبطال.
