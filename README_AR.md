# ICT بالعربي 7.0 — المرحلة 7C: التقرير الأسبوعي وخطة تحسين الأداء

## التركيب
ارفع الملفات الستة الموجودة في الحزمة إلى جذر مستودع GitHub، فوق آخر نسخة معتمدة بعد 7B. استبدل `smart-desk.html` و`sw.js` فقط، وأضف ملفات `ict-weekly-*.js/css`. لا تحذف ملفات 7A و7B ولا تمس بيانات المتصفح. لا تعِد تثبيت تطبيق PWA أو تمسح تخزينه دون أخذ نسخة احتياطية لسجل الصفقات والحسابات.

## أين الجديد؟
افتح `smart-desk.html#dna` ثم تبويب Trader DNA؛ أسفل لوحة ذكاء الأداء 7B ستجد «تقريري الأسبوعي — مراجعة الأداء وخطة التحسين».

## الجديد بعد التركيب
1. اختيار الأسبوع الماضي (افتراضي)، الأسبوع الحالي أو أحد الأسابيع الستة السابقة، مع نطاق تاريخ واضح.
2. قراءة بيانات الصفقات المحفوظة من نفس السجل الأصلي، وفصل الحسابات باستخدام فلتر الحساب الحالي.
3. ملخص للعدد وصافي/متوسط R ونسبة النتائج الموجبة وتراجع منحنى R وعدد مراجعات الصفقات.
4. مقارنة وصفية بالأسبوع السابق مع تنبيه خاص إذا كان الأسبوع الحالي غير مكتمل.
5. مقارنة الاستراتيجيات والجلسات؛ المتوسط لا يظهر إذا كانت المجموعة أقل من 5 صفقات.
6. اقتراح خطوات تدريبية محدودة بناءً على نقص المراجعات وأخطاء التنفيذ والالتزام الموثق؛ لا توجد توصيات تداول أو استنتاجات سببية.
7. حفظ اختيار تنفيذ الخطوات والملاحظات محليًا لكل حساب وأسبوع، وتصدير تقرير JSON دون تفاصيل الصفقات الأصلية.

## التوقيت والدقة
تحديد بداية الأسبوع الحالي يتم بتوقيت `America/New_York` (الإثنين حتى الأحد). سجل Trader DNA يحتوي تاريخ صفقة يدويًا لا توقيت تنفيذ مؤكدًا؛ يتم تقسيم الصفقات حسب **التاريخ المسجل** دون تحويله أو إعادة نسبته إلى أيام أخرى. بيانات النتائج وصفية وتخضع لجودة الإدخال وحجم العينة. لا يتم التحقق من Equity الحقيقي أو حسابات الوسيط.

## كيف تختبره؟
1. افتح غرفة المتداول > Trader DNA.
2. حدد الحساب الشخصي ثم «الأسبوع الماضي» ولاحظ النتائج.
3. غيّر إلى حساب ممول وتحقق أن النتائج تتغير ولا تختلط.
4. افتح «الأسبوع الحالي» ولاحظ تحذير مقارنة أسبوع غير مكتمل.
5. حدد خطوة من خطة التحسين، أضف ملاحظة، واضغط «حفظ الخطة محليًا».
6. أعد تحميل الصفحة وتحقق من بقاء الملاحظة عند اختيار الحساب والأسبوع نفسه، ثم صدّر JSON.

## الفحوص المنجزة
- اختبارات Node.js صريحة لبداية أسبوع نيويورك، التواريخ الكبيسة، فصل الحسابات، حساب النتائج والمقارنة، ومولد أهداف التحسين.
- فحص صياغة JavaScript وبنية HTML وروابط CSS/JS.
- اختبار Chromium معزول على 390px و1366px وفلاتر الحساب والحفظ ومنع التمرير الأفقي، مع محاكاة localStorage؛ ليس اختبار إنتاج على GitHub Pages.
- فحص سلامة ZIP.

## ما لم يُنفَّذ
- إرسال تقارير تلقائيًا أو مزامنة عبر أجهزة.
- توصيات تداول أو تنبؤات مستقبلية أو حكم بربحية استراتيجية.
- الربط الفعلي بحساب الوسيط أو تقييم آلي لصحة قواعد شركة التمويل.
