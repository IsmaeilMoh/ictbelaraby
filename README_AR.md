# ICT بالعربي — إصلاح جذري للهيدر 6.9.19.12

## السبب المؤكد في ملفات النسخة السابقة
- هيدر HTML قديم في الصفحات الداخلية.
- سكربت `site-unity.js` يعيد إنشاء الهيدر.
- سكربت `home-header-match-6919.js` يغيّر شكل الهيدر مجددًا.
- سكربت `site-shell-691911.js` يستبدله مرة أخرى.
- عدة ملفات CSS تتنافس على ارتفاع الهيدر، خصوصًا في «مساحتي» وعند مقاسات 760–900px.

## ما الذي تغير؟
1. وضعنا هيدرًا ثابتًا واحدًا في HTML لكل صفحة داخلية، فلا توجد استبدالات متتالية وقت التحميل.
2. أوقفنا استبدال الهيدر في `site-unity.js` عندما يكون الهيدر المعتمد موجودًا؛ تركنا التنقل السفلي والرابط الموحد لـ«المزيد» كما هو.
3. عدلنا `site-shell-691911.js` ليتوقف عن تغيير الهيدر **مع الاحتفاظ بمنطق التذييل الموحد الذي يعمل عندك**.
4. أزلنا روابط ملفات محاولات إصلاح الهيدر القديمة من الصفحات التسع، ووضعنا CSS جديدًا محدد النطاق والهيدر، لا يتدخل في بقية الصفحة.
5. أضفنا زر الثيم بالمكوّن الجديد مع بقاء محرك الثيم الأصلي.
6. جددنا رقم كاش الـPWA حتى لا يتم الاحتفاظ بالهيدر القديم في الملفات المخزنة.

## التركيب
هذه الحزمة تُركّب فوق 6.9.19.11. ارفع محتويات الحزمة إلى **جذر المستودع** مع الاستبدال. لا تحذف ملفات المستخدم أو البيانات أو محتويات القسم.
