# ICT بالعربي — المرحلة 2B: التخزين المحلي ومزامنة الشموع

**التركيب:** هذه حزمة تحديث جزئي فوق 2A بعد سلسلة تحديثات 6.9.19.16 والمرحلة 1. ارفع ملفاتها إلى جذر GitHub Pages، وأضف الملف الجديد `ict-candle-store-702b.js` واستبدل الملفات الخمسة الأخرى. لا تحذف ملفات قديمة ولا تستبدل مجلد الموقع كاملًا.

## ما ستلاحظه

في `trust.html#ict-live-2a`، أسفل جدول شموع Bybit، تظهر لوحة **تخزين الشموع ومراقبة الفجوات** وبها:
- عرض عدد الشموع المكتملة المخزنة لهذا العقد والإطار داخل المتصفح، وعدد الفجوات في التاريخ المحمل وآخر وقت مزامنة.
- استعادة الشموع المكتملة من IndexedDB عند فتح الصفحة مرة أخرى حتى قبل بدء الاتصال؛ هذه بيانات تاريخية محفوظة **وليست بثًا حيًا**.
- زر **مزامنة واستكمال التاريخ**، يطلب بحد أقصى 4 صفحات من Bybit V5 (حتى 1000 شمعة للصفحة) لمحاولة سد الفجوات الحديثة.
- زر **حذف شموع هذا العقد محليًا** بعد التأكيد، دون مسح سجل التداول أو بيانات بقية الموقع.
- عند الاتصال العادي، يستعيد المحرك البيانات المحلية ثم يستعلم من Bybit ويبدأ WebSocket؛ عند الانقطاع وإعادة الاتصال يقوم بمزامنة جديدة.

## حدود مهمة

- التخزين عبر IndexedDB محلي للجهاز والمتصفح الحالي، بدون سحابة أو مشاركة بين الأجهزة. مسح بيانات التطبيق قد يحذفه؛ لا تعتمد عليه بوصفه أرشيفًا دائمًا.
- تُخزَّن الشموع **المكتملة فقط**، بحد أقصى 3000 شمعة لكل عقد وإطار؛ لا تُحفظ الشموع الجارية بوصفها مكتملة.
- لا يستمر جلب البيانات في الخلفية عند إغلاق التطبيق؛ ملء الفجوات القديمة والكبيرة قد يحتاج مزود تاريخ أو خادم لاحقًا.
- عدد الفجوات يُحسب **فقط بين أول وآخر شمعة معروضتين**، ولا يعني أن كامل تاريخ السوق مغطى.
- بيانات Bybit لأسواق USDT الدائمة فقط؛ الفوركس والمعادن والمؤشرات والأسهم ستُربط في 2C. 2B يؤسس صيغة قابلة للتوسع، لكن هذا الإصدار لا يدّعي تخزين شموع تلك الأسواق بالفعل.
- عدم توفر IndexedDB (الوضع الخاص أو حظر التخزين) يعرض تحذيرًا؛ يبقى الاتصال الحي متاحًا.
- إن تعذر الاتصال بـ Bybit لا تُستخدم الشموع المحفوظة على أنها أسعار لحظية أو إشارات تداول.

## خطوات التحقق بعد النشر

1. افتح صفحة موثوقية البيانات، اختر BTCUSDT.P و15 دقيقة واضغط «اتصال وجلب الشموع»؛ راقب عدد الشموع المحلية والاتصال.
2. أوقف الاتصال ثم أعد تحميل الصفحة؛ ينبغي ظهور عدد الشموع المحلية السابقة قبل بدء بث جديد.
3. اضغط «مزامنة واستكمال التاريخ» وانتظر نتيجة عدد الطلبات والفجوات.
4. جرّب إطار 5 دقائق، ثم عد إلى 15 دقيقة؛ ينبغي فصل التاريخ المخزن حسب العقد والإطار.
5. جرّب حذف شموع العقد المختار محليًا، ثم إعادة المزامنة.

**المرحلة التالية تلقائيًا عند اعتمادك وقول «كمل»: 2C — ربط مزود أو مزودين للفوركس والمعادن والمؤشرات والأسهم.**
