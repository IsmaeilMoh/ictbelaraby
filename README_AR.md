# ICT بالعربي 7.0 — المرحلة 2E: مختبر نماذج ICT والتنبيهات المشروطة

## المتطلبات
يركّب هذا التحديث **فوق 2D المعتمدة**؛ ويحتاج ملفات المرحلتين 2A و2C وباقي ملفات الموقع الموجودة بالفعل. التحديث جزئي وليس نسخة كاملة للموقع.

## التركيب
ارفع الملفات التشغيلية الخمسة الموجودة في هذه الحزمة إلى جذر مستودع GitHub Pages، واستبدل فقط `trust.html` و`sw.js`، وأضف ملفات `ict-signal-*` الثلاثة. لا تحذف أو تعيد رفع الملفات الأخرى. اتصل بالإنترنت وأعد فتح التطبيق لتفعيل كاش PWA الجديد.

## ماذا ستلاحظ؟
- لوحة جديدة فوق مختبر 2D، بعنوان «مختبر النماذج والتنبيهات — ICT» داخل `trust.html#ict-signals-2e`.
- اختيار فئة السوق والأصل والإطار، وجلب الشموع الحقيقية من Bybit USDT للكريبتو وBiquote للأسواق التقليدية.
- العثور على تسلسل **سحب سيولة مؤكد ← MSS معاكس ← FVG** في الشموع المكتملة؛ عرض الحالة: بانتظار عودة السعر، إعادة اختبار، إبطال، انتهاء صلاحية، أو عدم صلاحية حساب مخاطرة.
- عرض وقت كل حدث، وحدود FVG، ومستوى السحب، ومستويات دخول ووقف وهدف **توضيحية فقط** (2R) عند إمكان حسابها.
- زران منفصلان: فحص يدوي للماضي، ومراقبة كل دقيقة **أثناء بقاء الصفحة ظاهرة**. زر ثالث لطلب صلاحية إشعارات المتصفح (اختياري).
- سجل أحداث جلسة المراقبة ومنع تكرار الإشعار نفسه عبر سجل معرفات محلي.

## الحدود والتعريفات
- النموذج البحثي مبسط ولا يعادل كل قواعد ICT الأصلية؛ لا يشمل الانحياز متعدد الأطر ولا الأخبار ولا التنفيذ، ولا يُنشئ أوامر تداول.
- فحص 2E يعتمد على محرك 2D؛ القمم لا تتأكد قبل اكتمال نافذة اليمين. أي فجوة زمنية تفصل المقاطع ويحلل المحرك أحدث مقطع متصل فقط. تُرفض الشموع المفتوحة.
- أقصى مدة من Sweep إلى MSS: 12 شمعة؛ FVG يجب أن تظهر بعد السحب وقبل MSS بحد أقصى شمعتين أو بعده بـ5 شموع. حالة المتابعة تنتهي بعد 6 شموع من اكتمال النموذج. إبطال عند إغلاق خلف حد إيقاف مشتق من شمعة السحب.
- واجهة الخطة السعرية توضيحية؛ لا تشمل السبريد والانزلاق أو فروق وسيط البيانات. لا تستخدمها كأوامر تلقائية أو توصيات شراء وبيع.
- لا تُرسل إشعارات تاريخية عند بداية المراقبة. لن تعمل المراقبة عند إخفاء الصفحة أو إغلاق التطبيق، ولا تعمل إشعارات Push من خادم. إعادة الفحص كل دقيقة مشروطة بتوفر اتصال الإنترنت ومصدر الشموع.
- مصدر Biquote طرف ثالث مستقل عن Bybit CFD، وقد لا تتوفر كل الرموز أو تغطية كاملة. تحقق من المصدر وتراخيص إعادة الاستخدام قبل نشر الإشارات تجاريًا.

## تجربة التحديث بعد النشر
1. افتح `https://ismaeilmoh.github.io/ictbelaraby/trust.html#ict-signals-2e`.
2. اختر BTCUSDT وإطار 15 دقيقة، واضغط «فحص النماذج الآن». ظهور «لا توجد نماذج مكتملة» نتيجة صحيحة وليست عطلًا.
3. اختر المعادن XAUUSD أو الفوركس EURUSD وكرر الفحص. راقب اسم مصدر البيانات وحداثة آخر شمعة.
4. اختر «بدء المراقبة أثناء فتح الصفحة»، واترك الصفحة ظاهرة؛ ثم أوقفها. السماح بالإشعارات اختياري ويحتاج إذن متصفح.
5. افحص أن هيدر الصفحة وتذييلها وأيقونة الثيم لم تتغير، وأن مختبر 2D وبقية لوحات البيانات تعمل.

## مستوى التحقق
تم اختبار الصياغة البرمجية ودمج المكونات والتحقق من تركيب HTML، واختبارات وحدة لمتتابعة Sweep/MSS/FVG، ولم يتم اختبار جلب مباشر على نسخة GitHub Pages المنشورة أو ضمان إرسال إشعارات على جهاز المستخدم. **المرحلة 2E جاهزة للتجربة وليست معتمدة إنتاجيًا بعد**.
