# ICT بالعربي — زر المزيد في هيدر اللابتوب (7.0.13)

## التغيير
إضافة زر «المزيد» في الهيدر الموحد على شاشة اللابتوب والكمبيوتر، يقود إلى صفحة «المزيد» الحالية في الرئيسية، مع ترك شريط الموبايل بعناصره الخمسة دون تغيير. لا يتم إضافة رابط «الأدوات» إلى الهيدر؛ مركز الأدوات موجود داخل «المزيد».

## التثبيت
انسخ ملفات الحزمة إلى جذر مستودع GitHub فوق الإصدار السابق، مع الاحتفاظ ببقية الملفات وعدم حذفها. الحزمة تتضمن 11 ملف HTML للصفحات التي تستخدم هيدر المنصة + ملفي JS/CSS + sw.js. في حالة تعديلاتك اليدوية الأخيرة على الصفحات الداخلية، احتفظ بنسخة احتياطية قبل الاستبدال.

## الاختبار
1. من اللابتوب افتح الرئيسية وأحد الأقسام الداخلية مثل «مركز فرص التداول» أو «مركز جميع الأدوات».
2. يظهر زر المزيد بجوار زر الثيم في الهيدر ويأخذك إلى قسم المزيد في الرئيسية.
3. افتح الموقع على الموبايل وتأكد أن زر المزيد في الشريط السفلي موجود وأن زر اللابتوب غير ظاهر.
4. إذا بقيت نسخة قديمة بعد النشر، أعد تحميل الصفحة دون الكاش أو أعد فتح التطبيق بعد تحديث Service Worker.

## النطاق
لا تعديل على المحركات أو بيانات التداول أو نماذج ICT. أداة التنقل تعمل في صفحات الهيدر الموحد المضمنة بالحزمة؛ لا تشمل صفحة الإدارة والأجندة المنفصلتين.
