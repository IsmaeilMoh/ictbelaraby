# ICT بالعربي — المرحلة 7B: ذكاء أداء المتداول

## التثبيت
ارفع الملفات الخمسة إلى جذر مستودع GitHub فوق تحديث 7A. استبدل smart-desk.html وsw.js فقط، وأضف الملفات الثلاثة الجديدة. لا تحذف بيانات المتصفح ولا تعِد تثبيت التطبيق دون تصدير نسخك الاحتياطية.

## الاستخدام
افتح غرفة المتداول: smart-desk.html#dna ثم تبويب Trader DNA. ستجد قسم «ذكاء الأداء — تحليل الحساب والنموذج والسلوك» قبل سجل الصفقات. استخدم فلتر الحساب والفترة والأصل والجلسة بالأعلى؛ يتغير التحليل معها. زر «تحديث التحليل» يعيد قراءة السجل من localStorage، وزر تصدير تقرير JSON يصدّر ملخصات فقط، وليس جميع تفاصيل الصفقات.

## الجديد
- ملخص صافي ومتوسط R، نسبة النجاح، التراجع بوحدة R، معامل الربحية، وتغطية مراجعة الصفقات.
- مقارنة حسب نموذج التداول والجلسة والأصل، وأخطاء التنفيذ والالتزام المصرح به.
- الحسابات الشخصية والممولة مفصولة باستخدام accountId المحدد في المرحلة 7A.
- حد مقارنات فرعية 5 صفقات؛ لا تُعرض متوسطاتها عند وجود أقل منها، وتحذير إجمالي عندما تكون العينة أقل من 30.
- تحليلات محلية وصفية؛ لا تضيف أو تحذف أو تعدل صفقات، ولا تقدم توصيات تداول أو تكشف بيانات للحاسب الخارجي.

## حدود مهمة
يعتمد التحليل على جودة الإدخال اليدوي وتصنيف الجلسة والاستراتيجية؛ لا يمكن إثبات سبب الخسارة أو الربح من التقارير. مقاييس R لا تعكس تغير Equity الفعلي أو قواعد حساب ممول، ولا يوجد ربط بالوسيط. لا تعني كثرة الربح في عينة صغيرة أفضلية مستقبلية. آخر ما تم اختباره هنا هو منطق JavaScript وربط HTML، وليس اختبار تشغيل على GitHub Pages المنشور.

## اختبار عملي
1. سجل صفقتين تجريبيتين لحسابين مختلفين بعد أخذ نسخة احتياطية.
2. غيّر فلتر الحساب وتحقق أن إحصاءات 7B تتغير ولا تختلط.
3. صنّف الالتزام والخطأ في صفقة؛ راجع تغطية المراجعة.
4. أعد فتح الصفحة وتحقق من بقاء الصفقات ونتائج التحليل، وجرّب تصدير التقرير.

## القادم
المرحلة 7C — تقارير أسبوعية وخطط تحسين قائمة على أخطاء التنفيذ والمراجعة الشخصية، دون تغيير خطة 8A–8C.
