# ICT بالعربي 7.0 — المرحلة 8C: تدقيق تكامل مركز القرار وجاهزيته

## طريقة التركيب
ارفع الملفات الموجودة داخل ZIP إلى جذر مستودع GitHub Pages **فوق آخر تحديث 8B**، واستبدل `decision-center.html` و`sw.js` وأضف الملفات الثلاثة الجديدة. لا ترفع المجلد الحاوي نفسه؛ المطلوب الملفات في جذر المشروع. لا تحذف أي ملف موجود أو تمسح بيانات التطبيق.

## ماذا سيلاحظ المستخدم؟
- لوحة جديدة في `decision-center.html#dc-readiness-8c` باسم «فحص جاهزية المحركات والبيانات — 8C».
- زر «فحص الجاهزية الآن» يدقق **عند الضغط فقط** تحميل محركات Bybit والأسواق التقليدية وICT والسياق والسيناريوهات والأخبار والحسابات ومركز الفرص، ثم يجلب عينات فعلية لشموع إطار الدخول والساعة من الأصل المختار، ويحاول قراءة ملفات الأجندة الثلاثة.
- رصد اكتمال الشموع وحداثتها والتكرار والفجوات والقيم غير السليمة، وتوضيح نتيجة فحص الحساب والمخاطرة إن اختير حساب.
- بيان مستقل لمتطلبات التشغيل 24 ساعة، وأسعار Bid/Ask التنفيذية، والاختبار الأمامي والترخيص التي **لا تزال غير متاحة**.
- تنزيل تقرير JSON يتضمن النتيجة والتفاصيل، بلا بيانات دخول أو مفتاح API.
- ملاحظة بعد فحص 8A: عدد النماذج وحالة الموانع العامة، دون وصفه بأنه توصية مؤكدة.

## ما لم يُنفذ
- لا يوجد خادم دائم لمراقبة جميع الأصول عند إغلاق الصفحة أو إرسال Push.
- لا يوجد Bid/Ask/Spread تنفيذي من الوسيط، ولا حجم عقد محسوب أو تنفيذ فعلي.
- لم تُجرَ اختبارات أمامية واسعة ولا إثبات ربحية، ولم تُثبت حقوق نشر جميع تغذيات البيانات.
- لا يغني الفحص عن التحقق من جودة المحركات على بيانات السوق المنشور، ومراجعة قرارات ICT المتخصصة.

## ملاحظات مهمة
- عند ظهور فجوات عبر عطل الأسبوع للفوركس والأسهم، قد يحتاج التدقيق إلى جدول جلسات تداول مرخّص ليحدد إن كانت الفجوة طبيعية أم انقطاع بيانات. لذا قد يكون محافظًا في تلك الحالات.
- يعتمد تدقيق 8C على مصدري Bybit للعقود USDT وBiquote للأسواق التقليدية وفق النسخة الحالية. لا تخلط هذه الأسعار مع عقود CFD لوسطاء آخرين.
- الحسابات والصفقات القديمة وسجل 8B تبقى كما هي. لم نلمس تخزين المستخدم ولا بياناته.
- تدقيق حالة المصادر لا يثبت بالضرورة قابلية إعادة نشر البيانات للعموم.

## الاختبارات المحلية المنجزة
1. `node --check` لملفات JavaScript المعنية.
2. 7 حالات من اختبار محرك الجاهزية: الشموع السليمة، والفجوات، والتكرار، والقدم، والقيم غير الصحيحة، والشمعة غير المؤكدة، وحالة الجاهزية المشروطة.
3. فحص وجود عناصر HTML والاستيراد.
4. تجربة لوحة 8C في Chromium على 390px و1366px مع محركات اتصال محاكية: الزر، التقرير، عدم وجود خطأ JavaScript أو تمرير أفقي.
5. التحقق من CRC في ZIP.

**لم ينجح اختبار رابط الموقع الكامل في Chromium المحلي** بسبب `ERR_BLOCKED_BY_ADMINISTRATOR`. الاختبار المباشر للواجهات الخارجية مطلوب بعد تركيب الحزمة.
