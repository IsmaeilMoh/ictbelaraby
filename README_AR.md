# ICT بالعربي 7.0 — المرحلة 6A

## المحتوى
تحديث جزئي للتركيب فوق 5C. انسخ الملفات الخمسة التشغيلية إلى جذر مستودع GitHub، واستبدل index.html وsw.js، وأضف ملفات 6A الثلاثة. لا ترفع هذا الملف للاستخدام التشغيلي إذا لم ترغب.

- index.html — ربط واجهة 6A بالأجندة القائمة دون تغيير شكل الهيدر أو القوائم
- sw.js — إصدار جديد لكاش PWA، دون تغيير مخزون البيانات الحية (يُطلب من الشبكة)
- ict-economic-link-706a.js — توحيد أحداث الأجندة وربطها بشموع ساعة مكتملة
- ict-economic-console-706a.js — واجهة الربط داخل قسم الأجندة
- ict-economic-console-706a.css — تنسيق معزول للواجهة

## ما الذي سيراه المستخدم؟
من الصفحة الرئيسية → الأجندة (#agenda)، أسفل محتوى الأجندة يظهر: «ربط الأحداث الاقتصادية بالشموع التاريخية».
1. اضغط «قراءة أحداث الأجندة»؛ تُقرأ الملفات calendar-live.json وcalendar-next.json وeconomic-official.json إن أمكن.
2. اختر خبرًا ذا توقيت صريح بالمنطقة الزمنية (UTC أو إزاحة).
3. اختر السوق والأصل (الفوركس، الذهب، المؤشرات، الأسهم، الطاقة أو كريبتو USDT).
4. اضغط «ربط الخبر بالشموع».
5. عند نجاح المطابقة: ترى الشمعة السابقة و«شمعة وقت الحدث» والشمعة التالية (ساعة لكل شمعة)، مع معلومات OHLC وصاحب مصدر السعر وتوقيت نيويورك وفلسطين.

## ضوابط الدقة
- لا يتم تخمين توقيت الأحداث المكتوب بلا منطقة زمنية واضحة.
- لا يتم استخدام شمعة جارية، ولا يُعتبر الربط صالحًا إلا إذا توفرت ثلاث شموع مكتملة ومتتابعة بالساعة.
- Bybit يُستخدم فقط لعقود الكريبتو USDT، ويجلب نافذة تاريخية حول الخبر من واجهة عامة.
- الأسواق التقليدية تُقرأ من مزودها العام الحالي Biquote، والذي يعيد فقط آخر عدد محدود من الشموع؛ لذلك قد يتعذر ربط حدث قديم، دون اختلاق بيانات.
- المؤشرات والأسهم تتبع مزود بيانات طرف ثالث وقد تختلف شموعها عن TradingView/وسيط CFD/جلسة التداول.
- لا توجد استنتاجات إحصائية عن قوة تأثير الخبر أو ارتباط سببي أو توصية بيع/شراء في 6A. تلك مهمة 6B/6C.
- لا يوجد خادم أو بيانات مستخدم تُرسل للموقع.

## فحوص تمت محليًا
- node --check لملفات JavaScript، واختبارات الأحداث المكررة والتوقيت الصارم والشموع المكتملة والفجوات.
- اختبار واجهة معزول بمتصفح Chromium بعرض موبايل 390px، دون تمرير أفقي أو أخطاء JS.
- اختبار تفاعلي محاكى لجلب الأحداث وتطابق ثلاث شموع حول خبر سابق.
- لم يتم اختبار وصول الملفات الفعلية من موقع GitHub Pages المنشور؛ يجب اختبارها بعد الرفع.
