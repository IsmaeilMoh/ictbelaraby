# ICT بالعربي — 6.9.19.14 — استنساخ الهيدر الأصلي للرئيسية

## ما الذي تغير؟
هذا التحديث يُلغي تقليد الهيدر السابق في الصفحات الداخلية ويستخدم **نفس بنية HTML وفئات CSS الموجودة في الصفحة الرئيسية**:
- `header.header` + `.header-inner` + `.brand` + `.brand-name` + `.brand-sub`.
- زر `#theme.theme-btn` نفسه، ليقوم `ui-icons.js` الأصلي بإنشاء نفس أيقونة القمر ومربعها الزجاجي (بدل SVG مخصص).
- تعتمد الهوية على نفس متغيرات الزجاج واللمعة والحدود في `ui-icons.css`.
- ملف التنسيق الجديد يحتوي فقط قواعد حصر الهيدر الداخلي ومقاسات الصفحة الرئيسية.
- لا تعديل للصفحة الرئيسية أو التذييل أو شريط التنقل أو بيانات التداول.

## التركيب
يركّب فوق 6.9.19.13:
ارفع ملفات HTML التسعة و`ict-home-header-exact-691914.css` و`ict-home-header-exact-691914.js` إلى جذر المستودع، واستبدل النسخ المطابقة.
**لا تحذف الملفات الأخرى من الموقع**؛ الملفات القديمة للهيدر لم تعد مستدعاة من الصفحات المعدلة.

## التحقق
نجح فحص سلامة وسوم الهيدر ووحدة زر الثيم وربط الملفات في الصفحات التسع، وصياغة JavaScript.
اختبار المتصفح الكامل تعذر بسبب حظر فتح المواقع المحلية في بيئة الاختبار، فاختبر الرئيسية وغرفة المتداول ومساحتي بعد النشر على جهازك.
إذا لم تتغير الواجهة، راجع أن ملفات HTML قد نُشرت وأن الرابط `ict-home-header-exact-691914.css?v=6.9.19.14` ظاهر في مصدر الصفحة.
