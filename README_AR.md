# تحديث المرحلة 2E — توقيت نيويورك وفلسطين

## التثبيت
ارفع الملفات الموجودة في هذه الحزمة إلى **جذر** مستودع GitHub Pages فوق المرحلة 2E. لا تحذف أي ملفات أخرى. أعد فتح الصفحة بعد تحديث Service Worker.

## التغيير المرئي
- **مختبر نماذج 2E:** يعرض وقت الفحص، آخر شمعة، وتوقيت تكوّن النموذج وسحب السيولة وMSS وFVG بصيغتي نيويورك وفلسطين.
- **سجل المراقبة 2E:** كل حدث جديد يحمل توقيت نيويورك وفلسطين.
- **مختبر 2D:** عرض وقت الفحص والشمعة وأحداث BOS وMSS وFVG بالتوقيتين.
- **جدول شموع الأسواق التقليدية 2C:** تعديل عنوان عمود الوقت والصفوف ووقت آخر شمعة ووقت الفحص بالتوقيتين.
- يتغير التوقيت الصيفي والشتوي تلقائيًا عبر IANA `America/New_York` و`Asia/Gaza`، وليس باستعمال فروق ساعات ثابتة.

## تفاصيل تقنية
- تبقى الطوابع الزمنية الخام والحسابات الداخلية بـUTC لتجنب تغيير تسلسل الشموع أو منطق الإشارات.
- التعديل خاص بالعرض في مركز الموثوقية؛ لا يغيّر بيانات المصدر أو الواجهة أو المخاطر أو التنبيهات.
- لا يشمل جدول Bybit 2A (يستخدم أصلًا وقت الجهاز المحلي) أو فحص مصادر الثقة القديم.
- أُضيف ملف توقيت مشترك جديد، وعُدّلت ثلاث وحدات عرض وملف HTML وService Worker.

## التحقق
- اجتازت ملفات JS فحوص صياغة Node، واختُبر تنسيق أوقات في الشتاء والصيف؛ وقد تختلف قواعد الانتقال التاريخية للدولة حسب قاعدة مناطق التوقيت في جهاز المستخدم.
- يحتاج عرض الموقع المنشور إلى تجربة المستخدم بعد التركيب.
