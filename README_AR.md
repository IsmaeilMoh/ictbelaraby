ICT بالعربي 7.0 — تصحيح المرحلة 2C (وصول عام بدون حساب)
====================================================
هذه حزمة تحديث جزئي تحتوي الملفات الأربعة التشغيلية فقط بالإضافة إلى دليل التركيب.

1. ارفع trust.html و sw.js و ict-public-markets-702c2.js و ict-public-console-702c2.js إلى جذر GitHub.
2. استبدل الملفات الموجودة وأضف ملفات JS الجديدة. لا تحذف أو تغير ملفات الموقع الأخرى.
3. افتح trust.html#ict-tradfi-2c أثناء الاتصال بالإنترنت.
4. اختر المعادن > XAUUSD > 15 دقيقة واضغط «جلب الشموع والتحقق من المصدر»، ثم كرر مع EURUSD وNAS100 والأسهم.
5. إذا لم تتوفر شموع لأصل ما، تظهر رسالة فشل واضحة؛ لا ينبغي اعتماد هذا الأصل إلى حين إثبات تغطيته.

مصدر الأسواق التقليدية لهذه التجربة: Biquote Public OHLC API (https://biquote.io/docs/).
لا يلزم الزائر حساب تداول أو مفتاح API. Bybit V5 يبقى للكريبتو USDT حصريًا.
هذا ليس الوصول إلى بيانات Bybit CFD / MT5، ولا يجوز تسمية الأسعار البديلة بالأسعار نفسها.
الرموز NAS100->USTEC و USOIL->WTI مجرد مطابقة مفترضة داخل قائمة الاختبار؛ لا تعتبر التغطية مؤكدة إلا إذا نجح الجلب.
لا تُعرض شمعة isOpen=true على أنها مكتملة. فحص الجودة يرفض بيانات OHLC غير الصالحة ويُظهر تأخر المصدر.
بيانات بعض الأصول (خصوصًا الأسهم) قد لا تتوفر؛ دعم أنواع الأسواق المذكور في وثائق المصدر لا يضمن تغطية كل رمز.
هذه تجربة مصدر عام من طرف ثالث. لم يتوفر اختبار اتصال مباشر من بيئة البناء بسبب حظر الإنترنت من الحاوية.
أي إعادة نشر واسعة أو استخدام تجاري يجب مراجعة شروط وترخيص البيانات مع المزود، وحتى التحقق لا تُستخدم هذه التغذية لإشارات تداول عامة.
هذه المرحلة لا تضيف تخزينًا دائمًا لشموع هذه الأسواق أو خدمة بث أثناء إغلاق التطبيق؛ الربط مع محرك 2B يتطلب اختبارًا مستقلًا لاحقًا.
الاختبارات البرمجية الآلية هي محاكاة لاستجابات المصدر وليست اختبارًا على بيانات الشبكة الحقيقية.
