# ICT بالعربي 7.0 — المرحلة 8B: متابعة الفرص وتوثيق نتائجها

## التركيب
- هذه حزمة **تحديث جزئي فقط** وليست نسخة كاملة.
- ثبّتها فوق النسخة المعتمدة بعد المرحلة 8A.
- ارفع الملفات السبعة الموجودة في ZIP إلى **جذر المستودع** مع استبدال الملفات المتطابقة، ولا تحذف غيرها.
- أبقِ جميع ملفات المحركات السابقة بما فيها ict-decision-engine-708a.js، وأصول التصميم والبيانات كما هي.
- بعد النشر افتح `decision-center.html` ثم أعد فتح التطبيق إذا ظل الكاش القديم.

## ماذا سترى؟
في صفحة مركز فرص التداول الذكي يظهر قسم جديد باسم «متابعة الفرص ونتائجها — 8B» أسفل نتائج الفحص.
1. افحص أصلًا وإطار 5 أو 15 دقيقة من خلال زر الفحص في 8A.
2. إذا وجدت فرصة، اضغط «حفظ الفرصة للمراقبة». إذا كانت معلقة بسبب جودة البيانات أو المخاطرة أو الأخبار، تُحفظ كمرجع معلق ولا تُحسب نتيجتها.
3. عد بعد إغلاق **شمعة جديدة** واضغط «فحص السوق وربط الأدلة» بنفس الأصل والإطار. لا يشترط بقاء فرصة جديدة لكي يتابع النظام القديمة.
4. سيحدّث القسم السجلات وفق شموع مكتملة لاحقة للرصد، ويتدرج: انتظار > ملامسة دخول > هدف/وقف/انتهاء/غير حاسم/فجوة.
5. يمكن فتح سجل انتقالات كل فرصة، وتصدير السجلات إلى JSON أو حذفها منفردة.

## ما يعمل داخليًا
- حفظ مستقل في `localStorage` تحت المفتاح `ict-8b-opportunities-v1`، أقصى 80 سجلًا؛ لا يغير حسابات/صفقات Trader DNA.
- يتم تجميد مستويات الدخول والوقف والهدف والمبررات عند حفظ الفرصة. التقييم اللاحق يمر على الشموع المكتملة **التي بدأت بعد لحظة التسجيل** فقط.
- كشف شموع مفقودة وتعليق التقييم بدل تخمين مسار السعر.
- إذا اجتمع الدخول والهدف أو الوقف داخل شمعة واحدة، أو اجتمع الوقف والهدف أثناء التتبع، تكون النتيجة «غير حاسم».
- النتيجة الحسابية بوحدة R لا تمثل صفقة منفذة؛ لا تؤخذ فيها أسعار Bid/Ask أو السبريد أو الانزلاق أو الرافعة.
- ينتهي تتبع الفرصة بعد 24 شمعة مكتملة ضمن جلسة التتبع، سواء تم التفعيل أو لم يتم.
- التقارير تحصي فقط الحالات المحسومة وليس الفرص المعلقة أو الملتبسة.

## ما لم ننفذه بعد
- لا توجد مراقبة خادم 24/7 عند إغلاق التطبيق، ولا إشعارات Push، ولا تنفيذ أوامر.
- لا تنشأ إشارة تلقائيًا بدون شروط 8A، ولا يثبت هذا النظام الربحية أو يتنبأ بالسوق.
- لا توجد مزامنة سحابية للسجل بين الأجهزة.
- الأرشيف التاريخي محدود بتغطية مصادر الشموع؛ لا نستنتج نتائج في الفجوات.

## التحقق قبل التسليم
- فحص `node --check` لملفات JavaScript المعدلة والجديدة.
- اختبارات Node لحالات LONG/SHORT، النتيجة الموجبة والسالبة، انتظار الدخول، انتهاء الصلاحية، الالتباس داخل الشمعة، فحص الشموع المكتملة، الفجوة، حفظ الحالة المعلقة، وإعادة الفحص.
- تأكيد وجود روابط الملفات الجديدة في HTML وذاكرة PWA.
- تجربة الواجهة عبر Chromium المحلي تعذرت بسبب منع وصول المتصفح إلى `file://` في البيئة. **لم تختبر الصفحة على الموقع المنشور**.
