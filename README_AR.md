التركيب: ارفع محتويات ZIP إلى جذر GitHub Pages فوق المرحلة 3B المصححة بتوقيت نيويورك. استبدل trust.html وsw.js وأضف الملفات الثلاثة الجديدة. لا تحذف ملفات 3A و3B و2D.

ما ستلاحظه: قسم جديد في trust.html#ict-briefing-3c أعلى السيناريوهات 3B. اختر السوق والأصل وحدود يوم نيويورك ثم «إنشاء / تحديث النشرة». النشرة تجمع مستويات PDH/PDL وPWH/PWL (إذا كانت البيانات تكفي)، والسيناريوهين والأدلة والإبطال والتحذيرات ووقت الإصدار والصلاحية بتوقيت نيويورك وفلسطين. يمكن تصدير TXT وقراءة أحدث 25 نشرة محفوظة محليًا.

التنبيهات: مراقبة اختيارية كل 5 دقائق أثناء ظهور الصفحة فقط. لا ترسل إشعارًا بسبب مسح تاريخي أو أول فحص، بل عند تغير ظروف نشرة سبق فحصها وكان مصدرها حديثًا ومُجتازًا؛ يجب منح إذن الإشعارات صراحة. لا يعمل بعد إغلاق التطبيق أو إخفائه، ولا يوجد Push خادمي.

الحدود: تعرض النسخ المحفوظة مع وقت صلاحيتها، وليس بوصفها أسعارًا لحظية. الساعات غير مكتملة/البيانات القديمة/نقص أسبوع نيويورك تبقى محذرة. لا تُحتسب الجلسات اليومية من شموع UTC اليومية؛ يعتمد المحرك على شموع الساعة وتحديد 17:00 أو 00:00 نيويورك من 3A. نتائج الإشارات بحثية وليست توصية أو تقييمًا للربحية.

لم يُعدّل: الصفحة الرئيسية أو الهيدر أو زر الثيم أو التذييل أو التنقل أو حسابات التداول، ولا يُضاف أي مفتاح API.
