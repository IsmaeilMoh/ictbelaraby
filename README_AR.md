# ICT بالعربي — تسريع استجابة الأيقونات والانتقالات 6.9.19.16

يُركّب فوق 6.9.19.15 مع بقاء الهيدر والتذييل والتصميم كما هي.

**ما تغيّر:**
1. عرض صفحة البداية بعد تحميل الملفات الأساسية مباشرة، من دون انتظار التغذيات الحية الإضافية؛ تظهر الأخبار والتقويم لاحقًا مع حالة المصدر.
2. خدمة PWA تقدم صفحات HTML وملفات CSS/JS التي سبق فتحها من الكاش فورًا، وتجددها بالخلفية؛ لا تخزّن الأخبار/الأسعار الحية كقيم حديثة.
3. تحسين استجابة روابط الانتقال: تهيئة الصفحات عند hover أو التركيز، دون الاستيلاء على النقر أو تغيير مساراته.
4. تحديث اسم الكاش لتفادي الاعتماد على ملفات الواجهة القديمة؛ تخفيف حمل تثبيت عامل الخدمة إلى الملفات الأساسية.

**ملاحظة:** أول زيارة إلى صفحة جديدة تتطلب الاتصال بالشبكة، وقد تبقى بطيئة حسب الاتصال. لا يُعد هذا الإصلاح تسريعًا مضمونًا لخادم خارجي أو روابط TradingView. ملفات الإدارة لا تُخزن في الكاش. يمكن أن تظهر نسخة واجهة محفوظة للحظة ثم تُحدّث عند الانتقال اللاحق.

## التركيب
ارفع ملفات ZIP إلى جذر المستودع مع الاستبدال. لا تحذف ملفات أخرى ولا تغيّر بياناتك. افتح التطبيق متصلًا بالإنترنت لإكمال تحديث Service Worker. جرّب النقر من الرئيسية ومساحتي ومختبر الأبحاث وغرفة المتداول.
