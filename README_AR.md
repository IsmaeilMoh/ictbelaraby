# ICT بالعربي 7.0 — المرحلة 8A: مركز فرص التداول الذكي المتكامل
تحديث جزئي (UPDATE ONLY)، يركب فوق المرحلة 7C وجميع الملفات السابقة من 1–7C، وليس نسخة مستقلة من الموقع.

## الملفات الموجودة في ZIP
- `decision-center.html` — الصفحة الجديدة
- `ict-decision-engine-708a.js` — منسق المحركات وقواعد الحجب
- `ict-decision-console-708a.js` — جلب البيانات وعرض النتائج والمراقبة عند فتح الصفحة
- `ict-decision-center-708a.css` — تنسيق الصفحة الجديدة فقط
- `app.js` — رابط جديد في قسم «المزيد» دون إعادة تصميم القسم
- `sw.js` — تحديث كاش PWA لتضمين الصفحة الجديدة وملفاتها
- `README_AR.md` — تعليمات وقيود التنفيذ

## التركيب
ارفع الملفات إلى الجذر نفسه الذي يحوي index.html وtrust.html وsmart-desk.html على GitHub Pages، واستبدل app.js وsw.js، وأضف الملفات الأربعة الجديدة. لا تحذف ملفات المراحل السابقة ولا تخزن كلمات مرور أو مفاتيح وسيط.

## أين ترى التغيير؟
1. الصفحة الرئيسية > المزيد > «مركز فرص التداول الذكي — 8A».
2. رابط مباشر `decision-center.html`.
3. اختر السوق/الأصل/إطار 5 أو 15 دقيقة/بداية يوم نيويورك.
4. اختر حسابًا شخصيًا أو ممولًا من الحسابات التي حفظتها في «مساحتي» (اختياري للفحص البحثي؛ إلزامي لمراجعة مخاطرة خطة).
5. أدخل مبلغ المخاطرة بعملة الحساب واضغط «فحص السوق وربط الأدلة».
6. راجع سياق PDH/PDL وPWH/PWL إن توافر، ونماذج Sweep-MSS-FVG الحديثة، وحالة الأجندة والحساب، وأسباب تعليق كل فرصة.
7. «تشغيل المراقبة أثناء فتح الصفحة» يعيد الفحص كل دقيقة ويُوقفه عند إخفاء الصفحة أو إغلاقها.
8. الملخصات تحفظ محليًا في المتصفح عند سماح المتصفح بالتخزين، وتعرض كفحوص قديمة بوسم واضح.

## المصادر المستخدمة والقيود
- العملات الرقمية USDT: Bybit V5 public candles.
- الفوركس والمعادن والمؤشرات والأسهم والطاقة: Biquote العامة، برموز USD الأصلية كما في 2C؛ **ليست شموع Bybit CFD أو أسعار تنفيذ وسيط بعينه**.
- تجميع سياق نيويورك من شموع الساعة بواسطة محرك 3A (حدود 00:00 أو 17:00 بحسب الخيار) مع التوقيت الصيفي والشتوي.
- محرك 2D للهيكل و2E للنموذج المركب و3B للسيناريوهات و6A للأجندة و7A لحسابات المخاطرة.
- الأخبار لا تعد متحقَّقًا منها إلا مع نجاح المصادر الثلاثة ووجود أحداث مؤرخة قريبة؛ وعند الفشل تعلّق صلاحية الخطة.
- عند الاقتراب من خبر متعلق بالأصل ±30 دقيقة، أو نقص الأجندة/المخاطرة/السياق/الشموع، تعرض الأسباب ولا تُجيز خطة جاهزة.
- صفقة واحدة تتطلب سعر Bid/Ask مباشر وسبريدًا ومواصفات عقد وحجم مركز وعمولات وانزلاقًا واختبارًا أماميًا. القيم التي يعرضها 8A افتراضية مشتقة من إغلاق شموع، لا أوامر أو توصيات تنفيذ مؤكدة.
- المركز يعتمد على فحص عند الطلب؛ وليس خادمًا يعمل دائمًا أو بث tick لحظيًا أو مراقبة للأسواق كلها في الخلفية. لا ينفذ أوامر تداول ولا يرسل إشعارات Push أثناء إغلاق التطبيق.
- لا توجد بيانات اعتماد أو مفاتيح API ضمن الحزمة.
- وصول البيانات وترخيص إعادة الاستخدام العام ومسارات شبكة الزائر خارج نطاق الاختبار المحلي ويحتاج تحققًا قبل الإطلاق العام.
- يظل تقييم Breaker التجريبي واختبارات ربحية بعض النماذج غير مكتملة، لذلك لا تُنتج من هذه النماذج إشارات تشغيلية هنا.

## ما لم يتغير
الهيدر والزجاجية وزر الثيم والتذييل وأزرار التنقل الحالية وبيانات الحسابات وسجلات الصفقات والمحركات القديمة؛ لا يحدث ترحيل بيانات أو مسح سجلات.

## الاختبارات المنفذة في بيئة البناء
- اختبارات Node: ربط 2D/2E/3A/3B وفحص مولّد الفرص وحجب الأجندة والمخاطرة والأخبار القريبة.
- متصفح معزول Chromium: اختيار الأسواق والعقود، إدخال البيانات، الفحص بمحاكاة مصدر، وعرض التقرير والتخزين عند توفير التخزين في الاختبار.
- مقاس 390 و1366 بكسل: لا أخطاء JavaScript ولا تمرير أفقي في الواجهة المعزولة.
- فحوص صياغة JS وسلامة ZIP والروابط.
- لم يكتمل اختبار الاتصال الحقيقي أو تفاعل جميع ملفات الصفحة على GitHub Pages؛ راجع النشر على جهازك.
