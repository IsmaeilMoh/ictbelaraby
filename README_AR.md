# ICT بالعربي — إصلاح نهائي للبنية المشتركة 6.9.19.11

## سبب المشكلة
كانت الصفحات الداخلية تحتوي على هيدر قديم، ثم يستبدله `site-unity.js`، ثم تطبق عليه طبقات CSS متعددة (6.9.19.3، 6.9.19.5، 6.9.19.7). كذلك كان التذييل موجودًا في HTML ولكن تعرضه قواعد تصميم مختلفة. وقد تحتفظ PWA بالملفات القديمة عند العمل دون اتصال.

## الحل
- مكوّن DOM واحد يولد ترويسة وفوتر موحدين للصفحات الداخلية التسع، بعد تحميل النصوص ومكونات الواجهة القديمة، من دون تعديل الصفحة الرئيسية.
- نفس النص الحرفي لتحذير الرئيسية، وروابطها وترتيبها وأسطرها السفلية.
- نفس ارتفاع الهيدر: 66px للموبايل و78px للشاشات الأوسع، مع شعار 42px وزر ثيم 42px، ولا يُسمح بصف ثان.
- قواعد تنسيق ذات أسماء فريدة، فلا تتأثر بتنظيم بطاقات ونماذج الصفحات الداخلية.
- تحديث كاش PWA دون تغيير ملفات الأيقونة أو شاشة الإقلاع.

## التركيب
ارفع محتويات ZIP إلى جذر المستودع، واستبدل ملفات HTML التسع و `sw.js`، وأضف `site-shell-691911.js` و`site-shell-691911.css`. **لا ترفع ملف README إذا لا ترغب.**

## التحقق بعد النشر
1. افتح الرئيسية ثم «مساحتي»، قارِن الهوية وحجم الهيدر مع تثبيت عرض الجهاز والثيم.
2. جرّب مختبر الأبحاث وغرفة المتداول ودليل الأصول ولوحة الإدارة.
3. افحص التحذير والروابط والسطر السفلي في نهاية كل صفحة.
4. غيّر الثيم، واختبر «المزيد» في الشريط السفلي؛ لم نعدّل وظائفه.
5. إن بقي التصميم القديم، أعد التحميل باتصال الإنترنت وأغلق تطبيق PWA وافتحه من جديد. لا تحذف بيانات التطبيق قبل تصدير نسخة احتياطية.

اختبارات الكود والأرشيف ليست بديلًا لاختبار بصري على الموقع المنشور.
