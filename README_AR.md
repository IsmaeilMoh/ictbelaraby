المحرك يستخدم API العامة السابقة: Bybit للكريبتو USDT وBiquote للأسواق التقليدية بحسب التوفر. لا يحتاج مفتاحًا ولا يُجري طلبًا في الخلفية. يحسب على إطار الساعة ويتعامل مع آخر 24 شمعة ساعة من المقطع الحديث فقط. يتوقف عن اعتماد البيانات إن لم تتوفر شموع مكتملة وحديثة. نتائج 2D هي وصف خوارزمي أولي وليست احتمالات نجاح.
