# ICT بالعربي — الإصدار التجميعي الواحد: مركز توليد الفرص + المراقبة المجانية

## قبل الرفع
- هذه **حزمة واحدة** تجمع واجهة مركز القرار ومحركاته، سجل الفرص، فحوص الجاهزية، واجهة الأدوات، وخدمة GitHub Actions المجانية.
- ارفع الملفات إلى **جذر المستودع الموجود نفسه** مع الحفاظ على المجلدات المخفية `.github/workflows` و`monitor-service`، واستبدل الملفات المطابقة دون حذف بقية ملفات الموقع.
- **لا تمسح بيانات المتصفح أو IndexedDB**: يحتفظ المشروع بحساباتك والصفقات وسجل الفرص محليًا.
- لا يلزم شراء VPS أو رفع Docker. هذه النسخة تعتمد جدولة GitHub Actions المجانية للمستودعات العامة.

## ما الذي أصبح موجودًا عمليًا؟
1. `tools.html` — مركز الأدوات ذات البطاقات والأيقونات، ويمكن الوصول إليه من الرئيسية.
2. `decision-center.html` — زر الفحص عند الطلب، أدلة ICT، سياق نيويورك، الأخبار، المخاطرة، سجل 8B للفرص الافتراضية، الجاهزية.
3. زر «قراءة أحدث فحص ونماذج ICT من GitHub Actions» — يعرض **نماذج حديثة مرصودة مع وقت الاكتشاف والدخول والوقف والهدف**، لكن بحالة *بحثي معلّق* حتى عند وجود نموذج.
4. `.github/workflows/ict-free-market-monitor.yml` — فحص مجدول كل 15 دقيقة **بحسب توافر GitHub Actions**، وليس ضمان مراقبة 24 ساعة.
5. مراقب Node يرفض الشموع القديمة والناقصة، ويُظهر حالة الأخبار، ويفشل بالإغلاق عند غياب البيانات أو توقيت الأخبار غير المؤكد.
6. الأخبار: إذا لم تُضبط `ICT_ECONOMIC_FEED_URL`، يحاول المراقب استخدام أجندة Biquote العامة (مصدر واحد فقط، غير معتمد للتحقق الرسمي). إن تعذرت أو لم تُثبت التغطية يظل الفحص معلقًا.
7. ملف `ict-monitor-feed/monitor-status.json` يُنشر في فرع منفصل **بعد تشغيل المهمة فقط**، ولا يحتوي بيانات الحسابات ولا أوامر التداول.

## خطوات النشر مرة واحدة
1. على GitHub، ارفع محتويات ZIP مع المحافظة على المسارات؛ وتأكد أن ملف `.github/workflows/ict-free-market-monitor.yml` موجود على الفرع الافتراضي `main`.
2. Settings → Actions → General: أذِن للـWorkflow، واضبط Workflow permissions إلى **Read and write permissions** (إن سمحت سياسة المستودع).
3. Actions → **ICT Arabic - free periodic market research** → **Run workflow**، ثم تحقق من نجاح جميع الخطوات.
4. تأكد من ظهور فرع `ict-monitor-feed` وملف `monitor-status.json` فيه؛ تحقق من `marketDataReady` و`lastCycleAt` و`observations`.
5. افتح `https://ismaeilmoh.github.io/ictbelaraby/tools.html` ثم مركز القرار `decision-center.html` واختر الأصل. اضغط «فحص السوق وربط الأدلة»، وجرّب زر «قراءة أحدث فحص ونماذج ICT من GitHub Actions».
6. إذا لم تظهر نماذج فورية لكن `marketDataReady=true`، **هذا ليس بالضرورة خطأ**؛ النموذج المركّب Sweep→MSS→FVG قد لا يكتمل في الشموع الحديثة. تأكد من أسباب التعليق والإخفاق قبل الاستنتاج.
7. للتأكد من وصول التحديث: أعد فتح PWA مع اتصال إنترنت أو حدّثه بعد تفعيل Service Worker الجديد، ثم تحقق من عنوان الصفحة والمزايا الجديدة.

## فحص النشر
- [ ] عنوان الأدوات يصل إلى الصفحة ويظهر البطاقات والأيقونات
- [ ] الصفحة الرئيسية لم تتغير وظيفيًا بخلاف مدخل الأدوات
- [ ] قائمة الأسواق تعرض الرموز المطلوبة
- [ ] فحص BTCUSDT/ETHUSDT يجلب بيانات Bybit عند إتاحة المصدر
- [ ] فحص XAUUSD/EURUSD يظهر حالة Biquote إن كان متاحًا
- [ ] عند فشل الأخبار تظل الفرص معلقة، لكن لا يختفي التحليل البحثي
- [ ] في نتائج GitHub، كل `observation` يحمل `status=research_only_blocked` و`executionApproved=false`
- [ ] ملف فحص عمره أكثر من 45 دقيقة لا يعرض أي نموذج كأنه جديد
- [ ] محفوظات الحسابات والصفقات لم تتغير
- [ ] اختبار المحتوى على شاشة هاتف فعلية

## الحدود الفنية الحاسمة
**هذا الإصدار ليس إثباتًا لجاهزية التداول الحقيقي.** لا نملك نتائج forward test كافية أو ربطًا إلزاميًا بوسيط التنفيذ أو ضمان سبريد وتنفيذ، ولم ننشر Workflow على حسابك من هذه البيئة. الاقتباسات المرجعية من Biquote إن ظهرت ليست سعر تنفيذ مضمون لدى وسيطك. لا تُستخدم أي خطة لشراء أو بيع حقيقي دون تحقق مستقل.

- GitHub Actions قد يتأخر أو يفوّت مهامًا؛ لا يُضمن تشغيل مستمر أو إشعارات مع إغلاق التطبيق.
- إذا كانت الأسواق التقليدية مغلقة، فقد تُرفض شموعها باعتبارها قديمة بدل اختلاق أحدث سعر.
- الأجندة المجانية لا تثبت تغطية كاملة أو نتائج رسمية؛ عدم وجود خبر في مصدر واحد لا يثبت عدم وجود أخبار.
- لا تُستنتج ربحية أو احتمالية نجاح من عدد النماذج؛ سجل 8B محاكاة OHLC ويُعلّق ترتيب لمس المستويات داخل الشمعة.
- لا ينقل النظام أرصدة حساباتك إلى GitHub Actions، ولا يحوّل البحث إلى صفقات فعلية.

## الاختبارات المحلية للنسخة المجمعة
```bash
cd monitor-service
npm test
npm run test:actions
```
`test:actions` يتحقق من بيانات النشر ومن الواجهة باستخدام أمثلة ثابتة **اصطناعية**، ولا يثبت اتصالًا حيًا بمزود الأسواق أو تشغيلًا على GitHub.
